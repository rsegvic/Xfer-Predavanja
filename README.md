# Data Structures and Algorithms – Lecture Materials

Materials for a course on data structures and algorithms: slides, notes, code examples and exercises, organized by lecture.

## Structure

Each lecture lives in its own numbered directory:

```
01-sorting-and-binary-search/
02-.../
```

Inside a lecture directory you will typically find:

- `README.md` – overview of the lecture, topics covered and learning goals
- `notes/` – lecture notes
- `code/` – code examples and reference implementations
- `exercises/` – practice problems
