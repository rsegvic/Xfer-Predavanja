# Data Structures and Algorithms – Lecture Materials

Materials for a course on data structures and algorithms, organized by lecture.

Each lecture is a **self-contained website used as a presentation** (reveal.js slides with interactive visualizations). Open the lecture's `index.html` in a browser; no build step or internet connection is needed.

## Structure

Each lecture lives in its own numbered directory:

```
01-sorting-and-binary-search/
02-.../
```

Inside a lecture directory you will find:

- `index.html` – the slides (open this)
- `assets/` – stylesheet and the visualizations (one JavaScript file per visualization)
- `vendor/` – vendored presentation framework (reveal.js), so the site works offline
- `README.md` – contents of the lecture and how to edit it
