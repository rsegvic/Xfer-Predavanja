# Lecture 1: Sorting and Binary Search

## Topics

- Why sorting matters
- Elementary sorts: bubble sort, selection sort, insertion sort
- Efficient sorts: merge sort, quicksort
- Comparing sorting algorithms (time, space, stability)
- Binary search on sorted data
- Lower bound for comparison-based sorting

## Learning goals

After this lecture, students should be able to:

- Implement and trace the basic sorting algorithms
- Explain the time and space complexity of each algorithm
- Implement binary search and reason about its correctness
- Choose an appropriate sorting algorithm for a given problem
